二、角度方波生成

测试范围需要充分覆盖不同幅值与频率，不只测试小幅、低频情况。保留已有驱动保护，不修改电流限制或屏蔽故障。

1. 大范围阶跃性能测试
   - 半幅 A=[1°, 3°, 5°, 10°, 15°, 30°，60,85]。
   - 频率 f=[0.1, 0.2, 0.5] Hz。
   - 执行上述幅值与频率的全部组合。
   - 每组至少5次正向和5次反向完整跳变。
   - 注意：±30°对应每次60°阶跃。
   - 若机械允许范围不足，依据实际限位缩小并记录，不得越过机械限位。

2. 连续方波跟踪测试
   - 半幅 A=[1°, 3°, 5°, 10°]。
   - 频率 f=[0.5, 1, 2, 3, 5] Hz。
   - 执行全部组合，每组至少10个完整周期。
   - 此部分允许响应来不及稳定，重点比较跟踪误差、
     实际运动幅值、力矩输出和饱和现象。
   - 未稳定时，不强行给出调节时间。
   - 上升时间和超调量仅在响应满足定义时计算。

3. 执行方式
   - 将各组合设置为可独立选择的测试项，避免每次必须跑完整矩阵。
   - 默认按幅值、频率逐级增加执行，并记录每组实际温度。
   - A/B采用相同测试矩阵；尽量交替运行，减少温度与顺序影响。
   - 保留每次保护触发、提前终止和未完成的数据。
   - 发生保护或故障时停止当前组，不自动复位后反复重试；
     记录原因，由现场人员决定是否继续。
   - 组间停留时间可配置，不把组间回中纳入响应指标。

4. 分析要求
   - 将正常跟踪、输出受限、未稳定、保护中断分别标记。
   - 高幅高频组合是控制能力边界测试，不能把其结果全部解释为
     PID在线性工作区的性能。
   - 同时报告实际生效的目标角度和实际输出，区分指令幅值大、
     但实际运动幅值没有达到的情况。

四、统一计算口径

如提供离线指标脚本，正反向采用同一归一化方法。

对每次完整跳变：
- 旧目标为 r0，新目标为 r1，阶跃幅值 Δr=r1-r0。
- 使用连续角度表示，归一化响应 x(t)=[y(t)-r0]/Δr。
- 上升时间：跳变后首次向上跨过 x=0.1 到首次向上跨过 x=0.9 的时间差；允许线性插值。
- 超调量：max(0, max(x)-1)×100%，窗口截止下一次跳变前。
- 调节时间：从跳变时刻到最后一次进入 |x-1|≤0.02 且保持到下一次跳变前的时间。
- 若窗口内未达到阈值、未稳定、初始条件不满足独立阶跃要求，或数据缺失，则明确标记，不填零、不伪造指标。
- 为避免末尾偶然入带被当作稳定，调节时间要求进入后至少连续保持0.2秒；若半周期不足0.2秒，该项标为不可评价。
- 稳态误差使用已判定稳定后的平台末段计算；未稳定时只报告“末段误差”，不要称为稳态误差。
- 原始信号不做时间平移来消除延迟，不用未声明滤波改善指标。

同一幅值、频率下，分别统计正向和反向，再汇总多次有效跳变的均值、标准差与有效次数。不同幅值、频率分别比较，不能混成一个总改善百分比。

如果老师后续指定其他阈值或定义，提供统一修改配置的入口。
